- 🐂 I build multi-tenant SaaS platforms with **.NET** on the backend and **Angular** on the frontend, where strict per-client isolation and access control aren't a nice-to-have, they're the job.
- ⚡ I treat **performance and reliability as decisions** — knowing when a read-heavy query belongs in Dapper, when a heavy workload deserves its own service.
- 🖼️ I built a dedicated **C++ microservice (Crow + libvips)** to take image processing off the main API and keep the platform responsive under load.
- 📊 Software engineering with a **data-driven mindset** — as comfortable profiling data in a Python notebook as in a C# service.
- 🎓 Pursuing an **MBA in Software Engineering at USP**, Brazil's top-ranked research university.
